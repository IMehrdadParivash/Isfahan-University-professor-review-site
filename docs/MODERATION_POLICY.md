# سیاست مدیریت محتوا

## اصل انتشار

نظر مثبت و منفی با معیار یکسان بررسی می‌شود. نارضایتی، امتیاز پایین، انتقاد از تدریس، امتحان، رفتار یا نمره‌دهی دلیل پنهان‌کردن نیست.

## موارد قابل مداخله

- اطلاعات خصوصی یا راه تماس اشخاص.
- تهدید، دعوت به خشونت یا محتوای غیرقانونی.
- جعل هویت یا ادعای نمایندگی نادرست.
- اسپم، تبلیغ، ارسال خودکار یا تکرار هماهنگ.
- حملهٔ فنی، تزریق کد یا لینک فریبنده.
- دستکاری امتیاز با ارسال‌های انبوه.

## فرایند

1. علامت خودکار یا Report کاربر، محتوا را وارد صف می‌کند.
2. مدیر متن، دلیل گزارش و الگوی سوءاستفاده را می‌بیند.
3. هر تغییر وضعیت به دلیل ۵ تا ۲۵۵ نویسه‌ای نیاز دارد.
4. وضعیت قبلی، جدید، اقدام و شناسهٔ هش‌شدهٔ نشست مدیر در Audit Log ثبت می‌شود.
5. پنل حذف فیزیکی نظر ندارد. حذف دیتابیس فقط باید برای الزام حقوقی/حریم خصوصی و با فرایند جداگانهٔ مستند انجام شود.

## وضعیت‌ها

| وضعیت | معنی |
| --- | --- |
| `published` | قابل نمایش عمومی |
| `pending` | نیازمند بررسی؛ هنوز عمومی نیست |
| `hidden` | پس از انتشار به‌دلیل تخلف روشن پنهان شده |
| `rejected` | محتوای غیرمجاز پیش از انتشار رد شده |

## رسیدگی به اختلاف

تجربه‌های متناقض کنار هم باقی می‌مانند. تعداد نظر، توزیع امتیاز و درصد پیشنهاد برای جلوگیری از برداشت نادرست نمایش داده می‌شود. اصلاح نام، دانشکده یا درس از مسیر `professor_change_requests` انجام می‌شود و نباید با Moderation نظر مخلوط شود.
