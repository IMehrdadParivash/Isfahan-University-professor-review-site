# اولویت‌بندی قابلیت‌ها

## P0 — آمادهٔ شروع عمومی

- ثبت ناشناس/نام‌دار، امتیازهای ساختاریافته و پیشنهاد استاد.
- صفحهٔ مستقل استاد، نمایش و مرتب‌سازی نظرها.
- رأی، Report، Rate Limit، Honeypot، تشخیص تکرار و HMAC.
- فیلتر Course/Term/Rating، Pagination و درخواست اصلاح/افزودن استاد.
- پنل مدیریت، Audit Log، اصلاح استاد و آمار پایه.
- SEO، Sitemap، Structured Data، Dark Mode و Responsive.
- بستهٔ پارس‌پک، Cron نگهداری و راهنمای Backup.

## P1 — پس از دریافت دامنه و تست محدود

- رابط کامل ثبت‌نام/ورود و بازیابی حساب؛ API پایه از قبل Feature Flag دارد.
- Turnstile تطبیقی فقط پس از عبور از آستانهٔ ریسک، نه برای همهٔ کاربران.
- اعلان به مدیر برای Reportهای حساس و داشبورد روند سوءاستفاده.
- آزمون بازیابی Backup و Runbook رخداد امنیتی.

## P2 — بعد از شکل‌گیری دادهٔ کافی

- محبوب‌ترین، بیشترین نظر و Trending با حداقل نمونه و بازهٔ زمانی شفاف.
- مقایسهٔ چند استاد بر اساس درس و معیارهای هم‌سنخ.
- Share Card/Open Graph اختصاصی و لینک مستقیم هر نظر.
- جست‌وجوی Full-Text سروری در صورت عبور حجم داده از توان فهرست محلی.

قابلیت‌های رتبه‌بندی و Trending قبل از نمونهٔ کافی فعال نمی‌شوند؛ در غیر این صورت چند نظر اولیه می‌تواند تصویر گمراه‌کننده بسازد.
