# امتیاز استادان دانشگاه اصفهان

وب‌سایتی فارسی، راست‌به‌چپ و کاملاً استاتیک برای جست‌وجو و بررسی استادان دانشگاه اصفهان. رابط عمومی عمداً ساده نگه داشته شده است: **هر استاد یک امتیاز کلی از ۵** دارد و کاربر در کنار آن تعداد بازخورد و شاخص‌های کلی تدریس را می‌بیند.

این پروژه بدون بک‌اند، پایگاه داده، API یا سرویس پولی اجرا می‌شود و برای انتشار روی Cloudflare Pages آماده است.

## هدف پروژه

هدف این مخزن فراهم‌کردن یک مرجع سبک، سریع و حریم‌خصوصی‌محور برای دانشجویان دانشگاه اصفهان است تا بتوانند استادان را بر اساس داده‌های عمومی و بازخوردهای پالایش‌شده پیدا و مقایسه کنند. داده‌های متنی خام یا شناسه‌های شخصی دانشجویان در رابط عمومی نمایش داده نمی‌شوند.

## امکانات

- جست‌وجوی فارسی با پشتیبانی از شکل‌های مختلف حروف، اعداد، فاصله و نیم‌فاصله.
- فیلتر دانشکده، گروه آموزشی و مرتبهٔ علمی.
- مرتب‌سازی بر اساس امتیاز کلی، تعداد بازخورد یا نام استاد.
- نمایش امتیاز کلی ۰ تا ۵ همراه با تعداد بازخورد مؤثر.
- نمایش شاخص‌های کلی تدریس و رفتار آموزشی.
- خلاصه‌های ناشناس و غیرنقل‌قولی از تجربه‌های دانشجویی.
- ذخیرهٔ محلی استادان و پوستهٔ روشن/تاریک.
- رابط واکنش‌گرا و سازگار با صفحه‌خوان.
- لودینگ سبک و بدون آواتار یا تصویر شخصی.

## روش امتیازدهی

دادهٔ ساختاریافته ممکن است از چند درس مختلف برای یک استاد آمده باشد، اما **در رابط عمومی تفکیک استاد × درس نمایش داده نمی‌شود**. امتیاز کلی استاد از میانگین وزنیِ میانگین‌های معتبر موجود محاسبه می‌شود و وزن هر بخش برابر تعداد گزارش‌های ساختاریافتهٔ آن است.

نمونه‌های تک‌نفره امتیاز عددی یا تاریخ دقیق عمومی تولید نمی‌کنند. بنابراین تعداد بازخورد کنار امتیاز باید همیشه در تفسیر آن لحاظ شود.

خلاصه‌های کیفی مستقل از امتیاز عددی‌اند و **هیچ تغییری در امتیاز استاد ایجاد نمی‌کنند**؛ فقط نکات تکرارشونده یا اختلاف‌نظرهای مهم را به‌صورت ناشناس منتقل می‌کنند.

## پالایش بازخوردهای متنی

فرانت‌اند متن خام چت را منتشر نمی‌کند. پیام‌های صرفاً پرسشی، تشکر، شوخی، تبلیغ، تکرار و ادعاهای شخصیِ فاقد ارتباط مستقیم با تجربهٔ آموزشی وارد خلاصه نمی‌شوند. نظرهای متناقض حفظ می‌شوند و موج‌های بسیار مشابه در بازهٔ زمانی کوتاه به‌عنوان چند شاهد مستقل با وزن کامل تلقی نمی‌شوند.

نام کاربری دانشجویان، متن خام چت، شماره تماس و ایمیل در رابط عمومی قرار نمی‌گیرند.

## اجرای محلی و آزمون

فایل `index.html` را می‌توان مستقیماً در مرورگر مبتنی بر Chromium باز کرد. برای بررسی فایل‌ها و ساخت بستهٔ انتشار:

```bash
python3 tools/validate-data.py
python3 tools/test-data-privacy.py
node tools/test-ui-runtime.cjs
python3 tools/test-release-safety.py
python3 tools/verify-assets.py
python3 tools/build-release.py
python3 tools/verify-assets.py --root .release/site
```

آزمون‌های مرورگر واقعی، در صورت وجود Chrome و Selenium:

```bash
python3 tools/test-browser.py
python3 tools/test-browser-ui.py
```

GitHub Actions روی تغییرات `main` و Pull Requestها، حریم خصوصی داده، یکپارچگی فایل‌ها، ایمنی انتشار، رابط کاربری و اجرای مستقیم `file://` را بررسی می‌کند.
