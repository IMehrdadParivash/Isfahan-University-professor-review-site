# سامانهٔ تجربه و امتیاز استادان دانشگاه اصفهان

یک سامانهٔ فارسی، RTL، موبایل‌محور و کم‌هزینه برای جست‌وجوی استادان و ثبت تجربهٔ دانشجویان. مشاهده و ثبت نظر ناشناس به حساب کاربری نیاز ندارد و نظر انتقادی صرفاً به‌دلیل منفی‌بودن حذف نمی‌شود.

## وضعیت فعلی

- فرانت‌اند Vanilla HTML/CSS/JavaScript؛ بدون فریم‌ورک و Bundle سنگین.
- API مستقل PHP 8.1+ با PDO؛ بدون Composer و سرویس دائمی.
- MySQL/MariaDB برای تولید و SQLite برای آزمون محلی Schema.
- ۷۴۳ استاد فعلی، ۱۷ دانشکده و ۶۴ واحد آموزشی موجود حفظ شده‌اند.
- صفحات مستقل و SEOپذیر استادان، Sitemap پویا و Structured Data.

## امکانات عملیاتی

### ثبت و نمایش نظر

- حالت‌های ناشناس، نام مستعار، نام واقعی و حساب اختیاری.
- متن، درس، ترم، نوع درس، پیشنهاد/عدم پیشنهاد و ۹ معیار ۱ تا ۵.
- معیارها: امتیاز کلی، کیفیت تدریس، سخت‌گیری، عدالت نمره‌دهی، سختی امتحان، رفتار، حضور و غیاب، حجم تکلیف و تطابق امتحان.
- مرتب‌سازی جدیدترین، مفیدترین، بالاترین و پایین‌ترین امتیاز.
- رأی «مفید بود»، «مفید نبود» و گزارش تخلف.
- آمار Cache‌شدهٔ هر استاد شامل میانگین‌ها، توزیع امتیاز و درصد پیشنهاد.

### ضدسوءاستفاده و حریم خصوصی

- CSRF، Prepared Statement، خروجی امن، CSP و هدرهای امنیتی.
- Rate Limit ساعتی/روزانه، Honeypot، تشخیص متن تکراری و محدودیت ارسال دوباره برای یک استاد.
- IP خام ذخیره نمی‌شود؛ شناسهٔ فنی با HMAC ساخته و بعد از ۹۰ روز فراموش می‌شود.
- شماره تلفن، ایمیل، تهدید، لینک‌اسپم و تکرار غیرعادی نظر را به صف بررسی می‌فرستند.
- حساب‌ها پیش‌فرض خاموش‌اند و برای نظر ناشناس لازم نیستند.

### مدیریت

- ورود امن مدیر با `password_hash`، CSRF و Rate Limit.
- صف یکپارچهٔ نظرهای مشکوک و گزارش‌شده.
- ثبت اجباری دلیل و Audit Log برای هر تغییر وضعیت.
- بدون حذف مستقیم نظر؛ وضعیت‌های قابل‌ردیابی `published`، `pending`، `hidden` و `rejected`.
- افزودن/ویرایش استاد و غیرفعال‌سازی بدون حذف تاریخچه.

## معماری

```text
مرورگر
├── فهرست سبک استادان (دادهٔ فشرده و Cache مرورگر)
├── professor.php (صفحهٔ مستقل و SEO)
└── api/index.php
    ├── ReviewService: ثبت، نمایش، رأی، گزارش و آمار
    ├── Security: CSRF، HMAC، Rate Limit و پالایش محتوا
    └── PDO → MySQL/MariaDB
```

قرارداد API از دیتابیس و UI جداست؛ بنابراین مهاجرت بعدی به VPS، PostgreSQL یا یک بک‌اند قوی‌تر بدون بازنویسی فرانت‌اند ممکن است.

جزئیات تصمیم‌ها: [معماری](docs/ARCHITECTURE.md)، [سیاست مدیریت محتوا](docs/MODERATION_POLICY.md) و [اولویت‌ها](docs/ROADMAP.md).

## راه‌اندازی روی پارس‌پک

به یک هاست لینوکس دارای PHP 8.1+، PDO MySQL، `mbstring` و MySQL/MariaDB نیاز است. Node.js لازم نیست.

```bash
python3 tools/build-parspack-release.py
```

بستهٔ `.release/parspack-site.zip` ساخته می‌شود. راهنمای کامل تنظیم دیتابیس، دامنه، Cloudflare، Cron و Backup در [PARSPACK_DEPLOY.md](PARSPACK_DEPLOY.md) است.

```bash
cp config.example.php config.php
# config.php را با اطلاعات واقعی و رازهای امن کامل کنید
php bin/install.php
```

`config.php`، Backupها و خروجی انتشار در Git ثبت نمی‌شوند.

## اجرای محلی و آزمون

برای رابط فقط‌خواندنی می‌توان `index.html` را مستقیم باز کرد. برای API، `db_dsn` را روی SQLite تنظیم و PHP داخلی را اجرا کنید.

```bash
python3 tools/validate-data.py
python3 tools/test-data-privacy.py
python3 tools/test-backend-contract.py
node tools/test-ui-runtime.cjs
node --check assets/js/reviews.js
python3 tools/test-release-safety.py
python3 tools/build-parspack-release.py
```

در CI، تمام فایل‌های PHP با `php -l` بررسی می‌شوند و تست‌های Chrome نیز Drawer، موبایل و اجرای آفلاین فهرست را کنترل می‌کنند.

## مسئولیت و وابستگی

این پروژه مستقل است و وابستگی رسمی به دانشگاه اصفهان ندارد. مدیر سامانه باید قوانین محلی، درخواست‌های معتبر حریم خصوصی، امنیت Origin و بازیابی Backup را پیش از انتشار عمومی بررسی کند.
