# امتیاز استادان دانشگاه اصفهان

وب‌سایتی فارسی، راست‌به‌چپ و کاملاً استاتیک برای جست‌وجو و بررسی استادان دانشگاه اصفهان. رابط عمومی عمداً ساده نگه داشته شده است: **هر استاد یک امتیاز کلی از ۵** دارد و کاربر در کنار آن تعداد بازخورد و شاخص‌های کلی تدریس را می‌بیند. برنامه بدون بک‌اند، پایگاه داده، API یا سرویس پولی اجرا می‌شود و برای انتشار روی Cloudflare Pages آماده است.

## امکانات

- جست‌وجوی فارسی با پشتیبانی از شکل‌های مختلف حروف، اعداد، فاصله و نیم‌فاصله.
- فیلتر سادهٔ دانشکده، گروه آموزشی و مرتبهٔ علمی.
- مرتب‌سازی بر اساس امتیاز کلی، تعداد بازخورد یا نام استاد.
- نمایش یک امتیاز کلی ۰ تا ۵ برای هر استاد، همراه با تعداد بازخورد.
- نمایش شاخص‌های کلی پیوستگی تدریس، دانش، انتقال مطالب، مدیریت کلاس، پاسخ‌گویی و رفتار با دانشجو.
- خلاصهٔ ناشناس و غیرنقل‌قولی از تجربه‌های دانشجویی برای استادانی که شواهد کیفی قابل‌استفاده دارند.
- ذخیرهٔ محلی استادان، پوستهٔ روشن و تاریک و رابط سازگار با تلفن همراه و صفحه‌خوان.
- آواتار محدود به صفحهٔ بارگذاری، با رعایت تنظیم کاهش حرکت سیستم.

## روش امتیازدهی

دادهٔ ساختاریافته در لایهٔ داخلی ممکن است از چند درس مختلف برای یک استاد آمده باشد، اما **در رابط عمومی تفکیک استاد × درس نمایش داده نمی‌شود**. امتیاز کلی استاد از میانگین وزنیِ میانگین‌های معتبر موجود محاسبه می‌شود و وزن هر بخش برابر تعداد گزارش‌های ساختاریافتهٔ آن است.

نمونه‌های تک‌نفره امتیاز عددی یا تاریخ دقیق عمومی تولید نمی‌کنند. در تفسیر هر امتیاز، تعداد بازخورد کنار آن باید دیده شود؛ امتیاز ۴٫۸ با چند گزارش محدود از نظر اطمینان با همان امتیاز و ده‌ها گزارش یکسان نیست.

خلاصه‌های کیفی مستقل از امتیاز عددی‌اند: آن‌ها **هیچ تغییری در امتیاز استاد ایجاد نمی‌کنند** و فقط برای انتقال نکات تکرارشونده یا تضادهای مهم در تجربه‌های دانشجویی استفاده می‌شوند.

## پالایش بازخوردهای متنی

برای متن‌های دانشجویی، فرانت‌اند متن خام را منتشر نمی‌کند. پیام‌های صرفاً پرسشی، تشکر، شوخی، تبلیغ، تکرار و ادعاهای شخصیِ فاقد ارتباط مستقیم با تجربهٔ آموزشی وارد خلاصه نمی‌شوند. نظرهای متناقض حفظ می‌شوند و موج‌های بسیار مشابه در بازهٔ زمانی کوتاه به‌عنوان چند شاهد مستقل با وزن کامل تلقی نمی‌شوند.

نام کاربری دانشجویان، متن خام چت، شماره تماس و ایمیل در رابط عمومی قرار نمی‌گیرند. خلاصه‌ها به‌صورت بازنویسی ناشناس ارائه می‌شوند و سطح پشتوانهٔ کیفی آن‌ها نیز مشخص می‌شود.

## داده و حریم خصوصی

| شاخص | مقدار |
| --- | ---: |
| استاد رسمی | ۷۴۳ |
| دانشکده | ۱۷ |
| واحد آموزشی وابسته به دانشکده | ۶۴ |
| عنوان متمایز گروه آموزشی | ۶۱ |
| مقیاس امتیاز عمومی استاد | ۰ تا ۵ |
| حداقل نمونه برای انتشار امتیاز ساختاریافتهٔ زیربنایی | ۲ گزارش |

قطعه‌های دادهٔ عمومی با SHA-256 اعتبارسنجی می‌شوند. فایل‌های JavaScript اجرایی نیز با شناسهٔ Git blob در `assets/data/dataset-manifest.json` به‌صورت دقیق allowlist شده‌اند تا تغییر ناخواسته یا فایل اجرایی اضافه توسط CI تشخیص داده شود.

## اجرای محلی و آزمون

فایل `index.html` را مستقیماً در مرورگر مبتنی بر Chromium باز کنید؛ نصب وابستگی و اجرای سرور لازم نیست. برای بررسی فایل‌ها و ساخت بستهٔ انتشار:

```bash
python3 tools/validate-data.py
python3 tools/test-data-privacy.py
node tools/test-ui-runtime.cjs
python3 tools/test-release-safety.py
python3 tools/verify-assets.py
python3 tools/build-release.py
python3 tools/verify-assets.py --root .release/site
```

آزمون‌های مرورگر واقعی، در صورت وجود Chrome و Selenium:

```bash
python3 tools/test-browser.py
python3 tools/test-browser-ui.py
```

GitHub Actions روی هر تغییر `main` و Pull Request، حریم خصوصی داده، یکپارچگی فایل‌ها، ایمنی انتشار، رابط کاربری و اجرای مستقیم `file://` را بررسی می‌کند.

## فونت و انتشار

فقط فونت محلی **Vazirmatn Regular/Bold** با مجوز **SIL Open Font License 1.1** منتشر می‌شود؛ متن کامل مجوز در `assets/fonts/OFL.txt` قرار دارد. فونت تجاری، آرشیو خصوصی و پوشهٔ `.release/` نباید وارد مخزن عمومی شوند.
